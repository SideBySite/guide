## 文体・記事の型
# 今回の編集範囲：ユーザー本人の逸話は扱わない
今回のガイドでは、ユーザー本人・製作者本人の観戦体験、私生活、個人的な思い出を調査・質問・執筆・転載しない。旧野球ガイドの「製作者のエピソード」やcontent/extra/maker.mdを今回へ引き継がず、掲載リンクや導線も作らない。
選手・監督・クラブ・競技の歴史に関する、出典で確認できる逸話は引き続き対象。ユーザーの観察の好みは編集方針として活用してよいが、本人の物語として本文にしない。本人の逸話を提供してもらう待ち合わせは作らない。

# 過去の野球ガイドから引き継ぐ編集仕様

# 口調・記事の型（過去の野球ガイドから引き継ぐ）
- 読み手はサッカーをまったく知らない大人。試合前やハーフタイムにスマホで1〜2分ずつ読む。15歳くらいの人に説明するつもりで、やさしく、ただし具体性を落とさない。
- 語り手は落ち着いていて感情をあまり出さず、淡々と筋道立ててやさしく説明する。文末は「〜なのだ」「〜というわけだ」「〜だ」を基本にする。読み手には「あなた」と呼びかけてよい。すべての文を機械的に「なのだ」にそろえない。
- 数字・選手名・場面・なぜそうなるかの理屈を入れ、なんとなくでごまかさない。たとえは身近なものを使い、最後にサッカーへ戻す。キャラクター名・作品名・決めぜりふを本文に入れない。
- 専門語は初めて出すとき必ずかっこで言い換える。昔の選手・チーム・賞も一言説明。1文40字前後、1段落3文まで。箇条書きは並列の項目だけ。
- 記事は1問1ファイル。L1は500〜1000字、派生L2は250〜600字が目安。理解に必要なら長くしてよい。見出しは「ひとことで」「しくみ」「歴史・由来」（あれば）「おもしろエピソード」（条件を満たす話があれば）「今日の試合で見るなら」。今日の欄は必須で、どの選手・どの場面・どこに注目するかを具体的に書く。
- 太字は初出用語・数字・選手名に1段落1〜2か所。==黄色いマーカー==は要点に1記事3〜6か所。補足は引用形式「> 」、関連リンクはIDでつなぐ。詳細名鑑にも同じ口調と装飾を使う。
- エピソードは、誰が／どんな場面で／何をしてどうなったかがそろう話。数字・成績だけ、しくみの言い換え、直近の結果報告で埋めない。面白さは①子どもでも笑える・驚ける②今日の見え方が変わる③なぜ？が解ける、の順。下品な話や締めのダジャレは使わない。見つからなければ無理に作らない。
