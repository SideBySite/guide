【1：試合に出そうな人を、根拠とともに選ぶ】
今季公式登録、現監督、直近公式戦3〜5試合の先発・ベンチ・交代・出場時間、公式の負傷／出場停止情報、今日のプレビューを確認する。所属・背番号・ポジション・年齢は現在の公式資料に照合する。
先発予想11人と、そのポジションを争う人、途中出場しそうな交代候補、控えGKまで、根拠のある当日のメンバー候補を原則全員扱う。目安は18〜23人。数を合わせるために出場根拠のない選手を加えず、実際の大会のベンチ枠に合わせる。外れる可能性が高い主力・負傷者は短い別表へ。
lineup.md に「予想」「発表済み」を分けた一覧と簡単な配置図の仕様を書く。各人の出場見込みは先発有力／先発争い／交代候補／不透明など根拠つきで示す。根拠のない確率％は作らない。ベンチ予想も確定扱いしない。発表済みなら公式メンバーを載せ、旧予想は更新前の情報と明示する。

【2：選手1人ごとの詳しいカード】
people/の1人1ファイルに、以下の内容を書く。先発候補・主要交代候補は600〜1000字程度、その他の出場候補も300〜600字程度を目安に、見どころを削って短い名鑑にしない。
- 名前・読み・背番号・年齢・代表的な位置／役割・利き足・体格。裏付けのある事項を記す。
- 「この人を一言でいうと」。プレーの強みと、得意を生かす条件／苦手な場面を、初心者に通じる具体的な動きで説明。
- プロまでの歩み、移籍や役割の転機、プロでの主な実績。年表の羅列だけにしない。
- 公開資料で確認できる人柄・習慣・サッカー外の話や、印象的な逸話を1つ。単なる成績紹介で埋めず、見つからなければそう書く。私生活の不要な詮索はしない。
- 今季と直近3〜5試合の役割・出場状況・調子。統計を使うときは対象大会と集計日を明示。移行期大会と現シーズンの成績を混ぜない。
- 今日の柏レイソル戦で、どの場面に出ると面白いか。交代候補はどんな局面で投入されそうかも、予想と明記して説明する。
- 「現地でこの人を追うなら」：いつ／誰またはどこ／何を見る／どう見えたら何が分かる、の順で観察ポイントを1〜2個。ボールを持つ場面だけにしない。背番号と位置で見つける手掛かりを添える。
- 断定できること・予想の区別、項目に対応する出典URL、確認時刻。
具体例の形：「相手が後ろでパスを回し始めたら、#○の走る方向を3回見る。一直線に追うのか、片側のパス道を隠すのか」。この例の動きを実際の全選手に当てはめない。実際に確認できる個性に合わせる。
