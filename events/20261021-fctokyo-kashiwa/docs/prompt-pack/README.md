## ページを増やす流れ

初期64問を入口に、00で疑問200〜280ページ程度を品質優先で検討します。人物カードは別枠。00-Jが追加分を1チャット6〜10記事へ分割し、runtime/にコピー可能な指示を生成します。人物確認も最大3人です。31はruntimeのrequired担当の実成果まで確かめ、初期64問だけで完成にしません。

HTMLの進行記録は端末内の手動記録です。「コピー」と「GitHubへの保存確認」を分けています。GitHubの状態を自動監視するものではありません。送信済みの重複依頼は避け、別チャットで作業中ならそのカードに記録してください。
