# 野球の表示を、サッカーの観戦画面へ置き換える

既存の白い本文、控えめな緑、濃い緑のスコアボード、黄色の数字、疑問から読む導線は引き継ぐ。球種やカウントを置換しただけの画面にはせず、サッカーの「今どういう時間か」「誰がどこにいるか」を入口にする。

[操作できるデザイン見本](prompt-pack/football-ui-preview.html)。スコア・背番号・配置は説明用の仮データであり、当日の実際の先発・速報ではない。

## 表示の対応

| 元の野球ガイド | サッカー版 |
|---|---|
| 回ごとのスコア、R/H/E | 両チーム名と合計得点を大きく。試合前はVS、未確認の得点は空欄・不明と区別 |
| 何回表・裏 | 試合前／前半／ハーフタイム／後半／試合終了と、確認できた試合時間・追加時間 |
| 塁のひし形と走者 | ピッチ上の先発11人の配置。先発一覧の直下に両チームの図を置き、狭い画面では縦に並べる |
| 打順と守備位置のスタメン表 | 背番号・氏名・公式登録位置と試合での役割。予想／発表済みを明示し、名前から詳細カードへ |
| 投手・打者 | 一対一の欄は廃止。「今見る場所」「交代した選手」の入口へ |
| B/S/Oランプ・アウトカウント | 廃止。対応するサッカーの数値はない。確認した得点・交代・警告・退場を出来事として表示 |
| 代打・代走・継投 | IN／OUTと時刻、交代前後に見るポイント。出場していない控えと交代済みを区別 |
| 球場写真から更新 | ビジョンの先発表・スコア写真から更新。サッカー用データをプレビュー確認して反映し、元へ戻せる |

## 野球版と共通にするトーンと配置（ユーザー指定）

野球版 `scripts/site_template.html` の画面を基準にする。白背景、本文最大680px、Noto Sans JPの16px本文、控えめな緑のアクセント、小さい見出し、横2列の質問・入口ボタン、濃緑のボードと黄色の数字を維持する。大きなキャッチコピー、広いヒーロー、ベージュの背景へ変更しない。

スマホでも上からの順序を野球版に合わせる。

1. 野球版と同じ小さな固定ヘッダー、2つのガイド入口（初心者／今日の見どころ）。
2. 試合ボード（サッカーの状態・両チーム・確認できた得点・時間）。
3. 野球版で「スタメン」があった場所に、両チーム11人の先発一覧。背番号・氏名・役割を示し、各選手の詳細カードを直接開く。
4. 先発一覧の直下に両チームのフォーメーション。本文目次の下や末尾へ移動しない。先発一覧と図で同じ11人を使い、両方から詳細人物カードへ接続する。
5. 「この画面の見方がわからないとき」の疑問ボタン、会場案内、柏・日立台の記事、検索へ続ける。

公開版の実装は `scripts/football_template.html`、先発表示データは `teams/lineups-display.json`。デザイン見本よりこの公開テンプレートとユーザー指定を優先する。モバイルで配置図を縦に並べても、先発一覧と同じブロック内に両チームを表示する。

## 配置図と人物

公式の先発発表だけで正確な左右・陣形まで確定しない。配置の根拠がないときは役割別の一覧を優先し、図を出すなら「配置イメージ」と明記する。保持時と守備時に形が変わることも説明する。4-4-2と3-4-2-1は見本のための仮配置で、当日の断定ではない。

各選手は背番号・短い表示名・押せる領域で示し、詳細名鑑の固定slugへ接続する。長い名前は2行以内で折り返す。ボタンは原則44px以上の押せる高さを確保し、横に詰めた4人は表示幅ごとにタップ領域の重なりを点検する。図だけにせず、スクリーンリーダーでも読める氏名・役割の一覧を併設する。チーム色は補助で、色だけで区別しない。

## 情報の状態

試合前のVSと、実際の0–0を混同しない。予想先発／公式発表済み／配置の解釈を別々に持つ。時計をブラウザの経過時間だけで自動進行させず、公式・写真・手動確認の時刻と最終更新日時を出す。「ライブ」は実際に速報を取得しているときだけ使う。

交代上限・交代回数・脳震盪の例外などを固定のランプへ押し込まない。採用規則を確認できた場合にだけ別欄で説明し、交代した人数と交代機会を混ぜない。VARは確認済みの状況だけを示し、実際の映像確認を見ていないのにアイコンを点灯させない。

## データの境界と写真から更新

イベント専用データに、match.status、period、display_clock、score.home/away、lineup_status、formation_basis、starters、bench、manager、events、sources、checked_atを分ける。野球のinning/count/bases/pitcher/batter/R/H/Eはサッカー用状態に持ち込まない。

写真を読む指示は、写っているチーム・氏名・背番号・得点・試合状態・表示時間だけを抽出する。読めない値を推測せず、欠落と0を区別し、片方だけの写真で反対側の情報を消さない。取り込み前に変更点を確認し、直前の状態へ戻せるようにする。氏名は固定slugへ照合するが、曖昧な同名者を自動で確定しない。

## 実装担当への引き継ぎ

31がイベント専用の画面へ実装し、35が320／390／680px程度の表示、状態切り替え、22人と控え・監督の人物リンク、長い名前、図が未確定の場合の一覧表示、更新前確認と復元を確認する。既存の野球site/index.html、scripts/site_template.htmlの公開画面は変更しない。デザイン見本の仮データを本番の試合情報として使わない。
