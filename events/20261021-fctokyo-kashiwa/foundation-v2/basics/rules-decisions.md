# なぜ笛が鳴った？　試合を止めるルールの入口

今日の**FC東京×柏**を初めて見るなら、全ルールを先に暗記する必要はない。==笛のあとに「誰のボールになったか」を見る==だけで、次のプレーを追いやすくなるのだ。

読み始める順番は、**接触→再開→カード**、次に**オフサイド**、後半には**交代→GK→審判・映像**だ。手に触れたように見えたら「ハンド」だけを開けばよい。９問の本文は独立しており、この目次には重複掲載しない。

既存ツリーの**2-01**へQ01・Q02、**2-02**へQ03〜Q05、**2-03**へQ06・Q07・Q09を対応候補とする。Q08はGK・当季の変更を独立して読む新しい問いだ。**1-02-b**（交代）の派生先にもQ07が使える。ここで正式なIDは採番・変更せず、草稿キー「01R-D-Q01〜Q09」を用いる。
