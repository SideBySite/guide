# 初めての90分を追うための9問

今日、2026年10月21日19:00の**FC東京対柏レイソル**は、味の素スタジアムで行われる2026/27明治安田J1第11節だ。まず、==11人ずつが相手のゴールへ進み、たくさん得点した側が勝つ==と覚えればよい。

**前後半は各45分**で、失われた時間が加わる。==同点で終われば引き分けで、延長戦も決着用のPK戦もない==。ボールが止まったら「どの線を越え、最後に誰が触ったか」を見ると、次の再開を予測できる。

## 試合前の短い読み方

開始前はQ01・Q03・Q04・Q05を読み、キックオフの時にQ06を開く。ボールが線を出たら、Q07からQ08かQ09へ進むとよい。==この目次は入口であり、各問の短い答えの後にしくみと今日の見方が続く==。

図を作る担当はQ03・Q06・Q07・Q09末尾の図の仕様を参照する。描いた図そのものを「今夜の実際の前半配置」と誤認させないこと。

> **担当の境界**：オフサイド、接触・ハンド、FK/試合中のPK、警告・退場、交代細則、VARの詳細は01R-Dに譲る。ここでは通常の得点・時間・方向・ボールアウトと再開に限る。

> **資料の時点**：本稿は2026年10月21日12:49 JSTを確認基準とする試合前資料。大会・適用ルールの公式発表は別の日付（Jリーグの改正適用告知は2026年7月23日）。記事の仮のIDは00-Jによる正式照合まで固定ID扱いしない。
