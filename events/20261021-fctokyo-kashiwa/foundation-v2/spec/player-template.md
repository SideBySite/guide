# 詳細人物カードの完全仕様（01R-F確定）

この型は**一人一ファイル、全見出し・全項目を残す**。2026年10月21日のFC東京対柏レイソル用であり、既存の英小文字slugを維持する。候補人数を減らさず、FCT-01〜09・KSW-01〜09に従い、**執筆、逸話、推敲、個別確認は1チャット最大3人**とする。5人ずつだった野球版の `scripts/build_prompts.py` の分量設定は継承しない。

- 名前欄には背番号、ポジション（主な持ち場と役割）、利き足、**試合日時点の満年齢**を書く。移籍・監督・所属は対象日のクラブ公式で再確認する。
- それぞれの欄を1〜3文で具体的に書き、年・大会名・数字・人物・対戦相手・場面を添える。**空欄にしない**。公開された根拠が本当に見当たらない時だけ「公開情報が見つかりませんでした」と書き、架空の逸話を作らない。
- **育成年代**、**プロ通算の変化**、**直近1年**、**直近3〜5公式戦**を別々に調べる。各段階の競技内のエピソード、競技外のエピソード、印象的な試合、実績を別項目で扱う。直近試合は出場／不出場・位置／時間／交代・得点等を原記録とともに記し、そこからわかることと予想を分ける。
- ゴール・アシストなどの成績は**大会名、試合対象期間、集計日**を明示する。2026年春の別大会、2026/27 J1、カップ、ACLを足さない。「調子」は公式記録から観察できる範囲を根拠に記述し、気持ちや故障を外見から推理しない。
- 観察の中心には**ボールを持たない時の位置**を入れる。今日出場するかは公式先発・控えが発表されるまで未確定。未発表なら「出場したら」で観察場面を示す。
- 文体は「〜なのだ／〜というわけだ／〜だ」が基本。落ち着いて説明し、初出専門語はかっこで言い換える。**初出名・数字**を1段落1〜2か所太字、**要点**を1カード3〜6か所 `==…==` で強調する。補足は `> ` で分ける。キャラクター名や決めぜりふを読者本文に出さない。
- 競技外の情報でも、本人・クラブ公式・取材記事など公開された範囲だけ。見た目の手がかりは現地で識別できるものに限定。本人の内心や私生活を創作しない。
- 事実ごとに対応する公式・取材URLを最後に置き、公開日、確認した日本時間、試合の日付を混同しない。初版の清宮幸太郎カード `data/players/detail/日本ハム-清宮幸太郎.md` は経歴の段階と具体性の**参考**であり、競技・時点・試合後の追記は移植しない。

## チェックと引き継ぎ

旧 `scripts/build_prompts.py` の `player_prompt`、`CARD_FORM` にあった**項目を省略しない／根拠を付ける／1人1ファイル**を受け継ぎつつ、サッカーに必要な利き足、ボールを持たない時、対戦相手との関係、直近の出場見込みと根拠を加えた。選手一人を仕上げるごとに**執筆→逸話→推敲→個別確認**の順に確認し、成果をその選手のslugへ保存・コミットする。ほかの選手の本文・共有の割当表・候補表は変更しない。

**逸話の基準**は[記事仕様](content-template.md)と同じ。選手／当時の場面／行動／結果が揃わない数字の列挙は逸話にしない。条件を満たさない場合でも**人物カードの欄は消さず**、その欄へ「公開情報が見つかりませんでした」と正確に記す（一般の記事で逸話の見出しを丸ごと消す規則とは区別する）。
