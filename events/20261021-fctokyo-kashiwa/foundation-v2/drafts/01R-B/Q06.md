# Q06 FC東京は今どこにいて、何を目指している？

## ひとことで

**FC東京は3位、勝点23**。首位・広島と勝点が並んでいる。==J1で初めての年間優勝を狙える位置==だが、まだ序盤であり、優勝に近いと決まったわけではない。

## しくみ

FC東京は第10節まで**7勝2分1敗**。21得点8失点で得失点差は**+13**だ。首位広島も勝点23だが得失点差は+19。勝点では追いついていても順位は3位なのだ。2026/27は38試合で、今日の前にまだ**28試合**ある。

クラブは以前、ルヴァンカップ（Jリーグのカップ戦）を2004年、2009年、2020年に制し、天皇杯（全国の勝ち抜き大会）でも2011年に優勝した。ただし**J1年間優勝の実績はない**。カップを持っていても、リーグ優勝とは別の記録というわけだ。

監督は**松橋力蔵**。10月17日の東京V戦に4-0で勝ち、J1では5連勝している。ただし連勝は過去の結果であり、柏戦の勝利を保証しない。柏も上位のため、今日の勝点を相手に渡さない意味がある。

## おもしろエピソード

2011年のFC東京はJ2で戦いながら、別大会の天皇杯決勝にも進んだ。京都相手に先制されたが、**ルーカス**（当時のFC東京のブラジル人攻撃手）が2ゴールを挙げ、4-2で勝った。==同じ年にJ2の優勝と天皇杯の優勝をつかんだ==のだ。大会が違えば、強さを証明する場面も違う。

## 今日の試合で見るなら

**長倉幹樹**はJリーグ公式プレビューで、ここまで7得点、さらにアシストでも中心と紹介された。==攻撃で3点を取りに行く姿勢と、失点しない守備を両方見る==。相手の柏も得点力があるので、ボールを失った直後にFC東京がどこで守り始めるかを観察するのだ。
