# 1対1で終わったら、どちらが勝ち？

## ひとことで

今夜の**FC東京対柏レイソル**は、2026/27明治安田J1リーグ第11節。試合終了時に両チームが同じ点なら、==どちらも勝たず、引き分けで終わる==。延長戦も、決着をつけるためのPK戦もない。

勝敗を数字で数えるなら、2対1は2点取った側の勝ち、0対0は引き分けだ。**勝点（順位を決めるために試合ごとにもらう点）**は、得点とは別の数字である。

## しくみ

J1は1試合ずつの勝敗を積み重ねるリーグ戦だ。2026/27の大会規定では、勝てば**勝点3**、引き分けなら両チーム**勝点1**、負けなら0。==ゴール数と勝点は混ぜない==ことが大切だ。

たとえばFC東京が2点、柏が2点を取って終われば、得点は2対2だが、勝点はそれぞれ1ずつ増える。4得点の試合だから4勝点を分けるわけではない。0対0でも両チームが得る勝点は1ずつで同じだ。

一方で、大会によっては同点から**PK戦（順番にゴール前から蹴って勝者を決める方法）**へ進む。2026年2〜6月の「百年構想リーグ」という別の特別大会には、90分同点後のPK方式があった。==そのルールを今夜のJ1へ持ち込んではいけない==。

> 試合中の反則により行うペナルティーキックも「PK」と呼ぶ。その1回のキックは今夜でも起こりうるが、引き分け解消のためのPK戦とは別物だ。判定の細部は01R-Dで説明する。

## 今日の試合で見るなら

もし**マルセロ ヒアン**がFC東京の得点に関わり、柏の**藤尾翔太**らのプレーで点が並んだとしても、残り時間に注目したい。終了の笛の時点で同じ点なら、そのまま引き分けである。==追いかける側が同点にした後の試合の進め方==を見ると、勝点1と3の違いが感じられる。

両選手の今日の出場は未確定の例だ。観戦中はまず電光掲示板の「得点」を見て、試合後の順位表で「勝点」を確かめよう。
