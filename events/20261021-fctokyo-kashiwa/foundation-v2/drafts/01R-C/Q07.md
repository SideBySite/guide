# ボールが白い線に触れたら、もう外なの？

## ひとことで

いいえ。ボールの全部が外へ出た時に初めて、**アウトオブプレー（プレーが止まる状態）**となる。==白い線の上にボールの一部でも残っていれば、まだ中==だ。地面を転がっても、空中を飛んでも、判定する考え方は変わらない。

スタジアムでは線ぎりぎりの場面が一瞬で過ぎる。観客席からの見え方と、実際の位置が違うこともある。

## しくみ

長方形の長い辺を**タッチライン（横の境界線）**、ゴールのある短い辺を**ゴールライン（端の境界線）**という。どちらを越えたかで、ボールの戻し方が違う。==まず「どの線を越えたか」、次に「誰が最後に触ったか」==を分けて考えるのだ。

たとえば柏の選手が線の上を転がるボールを追い、ボールが全部外へ行く前に中へ蹴り返したとする。この場合、まだ続けてよい。逆に空中のボールでも全体が線の外へ出れば、一度外になった事実は変わらない。

ボールがゴールの柱や横棒にはね返ってフィールド内に戻れば、基本的にプレーは続く。**主審（中央で試合を裁く審判）**が笛などで止めた場合も、ボールが線を出ていなくてもプレーは止まる。審判に当たった一部の場面にも特別な再開があるが、細部は01R-Dへ譲る。

試合の流れを追う時には、==ボールが止まった理由と再開方法は別の問題==だ。横からなら手で投げ、ゴール側の線からなら蹴って始めることが多い。次の2問でそれぞれを見る。

## 今日の試合で見るなら

柏の**久保藤次郎**やFC東京の**俵積田晃太**が出て外側を走るなら、タッチライン際での足元を見る。ボールが線に少しかかっている間は、そのまま運ぶことができる。==選手が追うのをやめた瞬間だけでなく、ボール全体の位置==に注目するのだ。

### 正確な図の仕様：インかアウトか

- 上から見た直線の白いタッチラインを、境界の「幅のある帯」として描く。帯の内側がフィールド、外側が観客席側である。
- 同じ直径の円を3つ別々に配置。「A：全部フィールド内」「B：線に少し重なる＝まだイン」「C：線の外側の縁から完全に離れる＝アウト」とする。
- 進行方向の矢印を外へ向け、地面・空中とも「ボール全体」の位置で判断する、と添える。ボールの中心が線を越えたことだけでアウトと描かない。
