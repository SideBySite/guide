# 横に出たボールは、なぜ手で投げるの？

## ひとことで

長い横の**タッチライン（フィールドの側面の線）**からボール全体が出たら、**スローイン（両手で頭の後ろから投げて再開すること）**を行う。==最後に触ったチームではなく、相手チームが投げる==のが基本だ。

たとえばFC東京の選手が最後に触れて外へ出したなら、柏のスローインとなる。どちらの席に近いかでは決まらない。

## しくみ

投げる人はフィールドを向き、ボールを両手で持ち、頭の後方から頭上を通して投げる。投げる瞬間は、両足のそれぞれ一部がライン上または外の地面に触れていなければならない。==片手で放り投げるだけでは正しい再開にならない==。

ボールがフィールドへ入った時から再びプレーが始まる。投げ入れる地点は、ボールが外へ出たところだ。スローインから直接相手のゴールへ入っても得点にはならず、相手側のゴールキックで再開する。

スローインは遠くまで投げなくてもよい。近くの味方が足元で受けると、その次のパスへつながる。==投げる人だけでなく、受け手が誰なのか==を見ると試合がつながるのだ。

> 2026/27の規則には、再開を不当に遅らせる場合の審判の5秒カウントがある。ただし、全スローインに機械的な5秒制限があるという意味ではない。細かな判定は01R-Dに譲る。

## 今日の試合で見るなら

FC東京の**石原広教**や柏の**久保藤次郎**が出るなら、その側のタッチラインからの再開を探してみよう。投げた直後に、前の味方だけでなく後ろへ戻すパスもありうる。==外に出たボールをどう安全に運び直すか==が、次の攻撃につながる。
