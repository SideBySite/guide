# DF・MF・FWはどこに立つ人？

## ひとことで

選手紹介の**DF（ディフェンダー＝守備寄りの人）**、**MF（ミッドフィールダー＝中盤でつなぐ人）**、**FW（フォワード＝前で攻める人）**は、仕事の目安だ。==立つ場所を固定する線ではない==のだ。

GK（ゴールキーパー＝ゴールを守る人）も含め、この4つの呼び名は試合を見るための地図になる。だが試合中、同じ人が何十メートルも移動する。

## しくみ

ゴールに近いDFは、相手のシュートを妨げたり、味方へパスを始めたりする。MFは両方のゴールの間で受け渡しをつなぐ。FWは相手ゴールに近い所で受けることが多い。

たとえば「4-4-2」という数字は、GKを除いて後ろに4人、中ほどに4人、前に2人という並び方の説明だ。**4＋4＋2＝10人**にGKが加わり、11人になる。==数字は出発時の並び方で、試合中の立ち位置の保証ではない==。

左端にいる人が中央まで移動することもある。背番号は選手を見分ける印であり、**背番号4＝必ずDF**という規則もない。同じ選手が守る時と攻める時で別の場所にいてよい。

## 今日の試合で見るなら

柏の**久保藤次郎**が出たら、右の外側から前へ進む時と、相手のボールになって戻る時を比べたい。FC東京の**高宇洋**が出るなら、後ろの選手からパスを受けられる中間の場所へ動くかを見る。==選手紹介の位置と、実際に動く道筋は別==なのだ。
