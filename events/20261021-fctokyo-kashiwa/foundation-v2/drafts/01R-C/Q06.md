# どちらへ攻める？ 後半に向きが変わるの？

## ひとことで

両チームは、それぞれ**相手のゴール**へボールを進める。前半と後半で守るゴールを入れ替えるので、==同じチームが攻める方向は後半に逆になる==。席から見て「今日は東京が右へ攻める」と試合中ずっと覚えるのは間違いだ。

**ホーム（主催側）**のFC東京が前半にどちらを攻めるかも、ホームだから必ず決まるわけではない。

## しくみ

試合前に審判がコインを投げる。勝ったチームは、前半に攻めるゴールか、最初の**キックオフ（中央からボールを蹴る開始方法）**を選ぶ。反対側のチームは、残った方を選択する決まりだ。

選手は前半を始める時、原則自分の陣地側へ入る。キックオフでは中央の印に置いたボールが、蹴られて明らかに動くと試合が始まる。必ず前方向へ蹴らなくてもよい。

前半の終わりにはいったん休憩し、後半は両チームが陣地を入れ替える。前半の最初のキックオフをした側と、後半を始める側も入れ替わる。==攻めるゴールと開始の担当の両方が変わる==のだ。

ゴールが決まったあとは、失点したチームが中央から再開する。たとえば柏が先に得点したら、その次のキックオフはFC東京。これで再び両チームの攻撃と守備が動き出す。

## 今日の試合で見るなら

試合が始まったら、FC東京のGK**キム スンギュ**がどちらのゴールを守るか見てみよう。彼が今日も出場するなら、後半開始の時には反対側のゴールに立つ。==チームの色より「その半分で誰が守っているか」==が攻める方向を見分ける確かな印だ。

### 正確な図の仕様：前後半の攻撃方向

- 同じ長方形のフィールドを、左に「前半」、右に「後半」で2枚描く。上端・下端にゴール、中央にハーフウェーラインとセンターマークを描く。
- **仮の配置**として、前半のFC東京のGKを下端、柏のGKを上端に置く。前半は東京の矢印を上向き、柏を下向きにする。
- 後半は東京GKを上端、柏GKを下端へ反転させ、矢印も逆にする。これは作図上の例であり、今日の実際の前半の陣地を決めつけない。
- 観客席側の左右・ホームと攻める方向を固定的に結びつけない。コインの選択を図中にも明記する。
