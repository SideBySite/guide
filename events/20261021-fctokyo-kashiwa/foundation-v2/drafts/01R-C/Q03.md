# ボールがネットを揺らせば必ず1点？

## ひとことで

得点になるのは、ボール全体が、**2本のゴールポスト（左右の柱）**と**クロスバー（上の横棒）**の内側でゴールラインを越えた時だ。反則などで認められない場合を除き、==どんな方法で入っても1ゴールは1点==となる。

見た目で「ほとんど入った」と感じても、ボールの端が線に残っていれば得点ではない。ネットは結果を見やすくするものだが、判定の基準そのものではない。

## しくみ

ゴールの入り口は、左右の柱の間、横棒の下にある。地面の白い線を**ゴールライン**といい、その面をボール全部が通過して初めて得点になる。空中で越えても、地面を転がって越えても同じだ。

ボールは丸いので、中心だけが線を越えても残りが線上にあることがある。==基準はボールの中心ではなく全体==。守る人が線ぎりぎりで蹴り返した時は、この違いが重要になる。

得点した側の数字が1つ増え、相手側が中央から**キックオフ（中央に置いたボールを蹴って再開すること）**を行う。たとえば0対0からFC東京に認められたゴールが1つ入れば1対0だ。続いて柏が1つ決めれば1対1へ戻る。

ただしゴールへ入る前の反則などで、得点が取り消される場合もある。==ネットに入る場面と、主審が得点を認めることは分けて見る==のだ。詳しい反則・映像確認の条件は01R-Dの担当範囲だ。

## 今日の試合で見るなら

FC東京の**マルセロ ヒアン**や柏の**藤尾翔太**が今日出場してゴール前へ向かうなら、シュート直後より一拍長く見てほしい。GKの位置、ボールが完全に線を越えたか、主審がどう再開させたかを順に追うのだ。==最後に中央から再開するのが、得点成立を確かめる手掛かり==になる。

### 正確な図の仕様：ゴールラインの判定

- 真上からの部分拡大図とし、横方向をゴール幅、縦方向をフィールド内→ゴール内とする。白いゴールラインを帯として描く。
- 直径を同じにしたボールの円を2つ置く。「A」は円の一部が線に重なり「まだ得点ではない」。「B」は円の全体がラインのゴール側の縁を越え「得点の位置」と注記する。
- 両ポストの内側・クロスバーの下を通る必要も、小さな正面図で補う。線の中央に球の中心が来ただけで得点と描かない。

> これはルールの説明図で、今日の特定のシュートの実測図ではない。
