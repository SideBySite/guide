# なぜ11人ずついて、全員がボールを追わないの？

## ひとことで

サッカーは、1チーム**11人**、両チーム合わせて22人で始まる競技だ。うち1人は**ゴールキーパー（GK＝ゴールを主に守る人）**で、ほかの10人は前後に動きながら攻守を分担する。==全員がボールに集まると、別の場所が空いてしまう==のだ。

選手が足を止めていても、ただ休んでいるとは限らない。相手のパス先をふさいだり、味方が受けられる場所を残したりする動きも、試合を進める仕事だ。

## しくみ

競技規則では、同時にフィールドに立てるのは各チーム最大11人。その中にGKが1人必要で、7人未満では試合を始めたり続けたりできない。交代で入る控え選手は、この22人の数には含めない。

GK以外の人は、原則として手や腕でボールを扱えない。GKも==自分のペナルティーエリア（自分のゴール前の大きな四角）内だけ==、規則で許される場面に手を使える。GKが何でも手で触れるわけではないことは、別のルールの疑問へ回せばよい。

たとえばFC東京の前の選手がボールを持ったとする。柏の3人が同じ人に飛びつけば、その後ろに空く場所へ別の東京の選手が走れる。守る側は、==ボールの近くと離れた場所を同時に守る==必要がある。

ボールを奪った瞬間には、仕事が逆転する。さっき攻めていた人が戻り、守っていた人がパスの受け手になる。野球のように攻撃と守備で選手全員を入れ替えないのだ。

## 今日の試合で見るなら

10月17日のJ1で先発したFC東京の**マルセロ ヒアン**が今日も出るなら、彼がボールから離れた場所にいる瞬間を見る。柏の**古賀太陽**が出るなら、前に出て守る人の後ろをどう補うか注目しよう。==ボールの周囲だけでなく、その後ろにいる一人==を見ると22人の意味が見えてくる。
