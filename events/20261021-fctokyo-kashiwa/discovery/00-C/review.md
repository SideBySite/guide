# 00-C 候補レビュー：戦略の種類と相性

## まとまり（全42問）

- **C-01〜10：ボール保持と速攻**（10）。後ろへ戻す／引きつける／奪った直後の時間／攻めながら後ろに残る人。見る行動を「出し先」「相手が一歩寄る前後」「失った際の残り人数」で分けた。
- **C-11〜20：追う・下がる守備**（10）。二人で追うこと、前後の連動、パスの線を消す、背後の危険、抜かれた仲間の助け、密集への攻め。前から守るか下がるかの二択で終わらせない。
- **C-21〜30：中央・サイド・背後**（10）。遠くで待つ、相手を寄せる、追い越す、反対側へ変える、高低の折り返し、相手守備の間への位置取り。ボールのない選手の動きを入口にした。
- **C-31〜42：配置・セットプレー・今日の相性・点差と時計**（12）。最近の布陣4-4-2／3-4-2-1を静止した正解ではなく、相手が向き合う場所の仮説にする。CKの蹴る前と短いCK、交代、勝点を使う終盤判断まで。
- 内訳：カテゴリ4が35問／カテゴリ5が7問。L1が11問／L2が31問。starが23問。基本64問のIDは保持し、ここでは仮IDのみ使用。

## 重複を避ける判断

- 既存の `4-01`・`4-02`・`4-03` と `5-03` は地図として扱い、候補は一場面の「狙い→代わりに空く場所→相手がどう邪魔する」の因果に切り分けた。
- 「長いパス」は **C-07**（奪った直後の最初の選択）／**C-10**（持ち続けた後の切替）／**C-26**（横方向の逆側への展開）で答えと観察対象が異なる。
- **C-11**（前線二人の協力）／**C-13**（前後の連動）／**C-14**（パスの通り道を隠す角度）／**C-37**（今日の2対3）は役割・方向・固有の対面が異なる。
- 反則、オフサイドの正式な判定、CKの再開手続きはカテゴリ2・1の既存問へ委ね、戦略に関係する必要最小限だけ触れる。

## 見送った案

- 「ポゼッション率が高ければ勝つ？」を統計相関の断定にする案：C-09の体感と保持率の違いに統合。勝敗の因果を一つの数字に還元しない。
- 「柏は必ず3バックで攻める」「東京は必ず前線で奪う」：今日の発表・動きが未確定なので、断定せず条件付きのC-31〜38へ。
- 「オフサイドラインはどの位置？」は2-01群と重なるので見送り。C-30は蹴る直前に走り出す時間の話に限定。
- GKの手の使用、FKの直接／間接、VARなどの手続き：カテゴリ2と重なるため戦術候補に水増ししない。
- 「同点ならPK戦？」：今夜は2026/27通常J1リーグで、90分で同点なら引き分け。2026年春の特別大会の制度を混ぜない。
