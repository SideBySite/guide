## ひとことで

==**交代**を見るときは、入る1人より**残る10人の並び**も大切だ。== 人が代わると、空ける場所と守る場所が変わるのだ。

## しくみ

**FC東京**は10月10日の浦和戦、後半16分に**佐藤恵允#10**と**大森理生#15**を入れた。クラブ評では、**石原広教#22**が右から左へ移り、大森が右に入った。==交代していない石原の動きまで含めて作戦が変わった==例なのだ。

**柏**は10月3日のG大阪戦（延長120分）で、**瀬川祐輔#20**と**細谷真大#9**を69分、**弓場堅真#44**を81分に投入。瀬川は90＋3分のPK（反則によるゴール正面からのキック）、弓場は103分と109分に得点した。==途中から入る人が、攻撃の出口を増やすことがある。==

**図案3：交代の前後**（上が相手ゴール。左右は説明上の位置）

```text
        ↑ 攻撃方向
      交代前      交代後
    ┌────────┐ ┌────────┐
    │   前   │ │   前   │
    │ 左  右 │ │ 左  新 │
    │   中   │ │   中   │
    └────────┘ └────────┘
  「右」が出ても「左」が
  右へ動く場合もある
```

交代が得点を保証するわけではない。相手も立つ場所を変え、守り方を修正できる。10月17日の柏は**GK若原智哉#77**が接触後に交代したが、これは攻撃上の選択と同列に扱えない。

## 今日の試合で見るなら

後半、東京に**山田楓喜#71**や柏に**細谷#9**が入るなら、==入る前と後で外の幅、中央の人数、前から追う人==を数えてみよう。出場しなければ、同じ役割の交代者を追えばよい。ベンチが動く理由を見た目だけで決めないことも大切だ。
