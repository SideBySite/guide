## ひとことで

==**交代**では、入る1人だけでなく、**残る10人の並び**も見よう。== 一人が代わると、ほかの人が守る場所や立つ場所も変わるのだ。

## しくみ

**FC東京**は10月10日の浦和戦で、後半16分に**佐藤恵允#10**と大森理生#15を入れた。クラブ評によると、石原広教#22が右から左へ動き、大森が右に入った。==交代しなかった選手の場所も変わった==、具体的な例なのだ。

**柏**は10月3日のG大阪戦（延長120分）で、**瀬川祐輔#20**と細谷真大#9を69分、弓場堅真#44を81分に入れた。瀬川は90＋3分のPK（反則による、ゴール正面からのキック）を決めた。

弓場も103分と109分に得点した。==途中から入る人が、攻撃の選択肢を増やすことがある==のだ。

**図案3：交代の前後**（上が相手ゴール。左右は説明上の位置）

```text
        ↑ 攻撃方向
      交代前      交代後
    ┌────────┐ ┌────────┐
    │   前   │ │   前   │
    │ 左  右 │ │ 左  新 │
    │   中   │ │   中   │
    └────────┘ └────────┘
  「右」が出ても「左」が
  右へ動く場合もある
```

交代すれば得点できるわけではない。相手も立つ場所を変えて守り直せるからだ。

10月17日の柏は**GK（ゴールキーパー）若原智哉#77**が接触後に交代した。これは攻撃のための交代とは、分けて考える必要がある。

## 今日の試合で見るなら

後半、東京の**山田楓喜#71**や柏の**細谷#9**が入るなら、==交代前後の外の幅、中央の人数、前から追う人==を比べよう。出ていなければ、同じ役割の交代選手で試せる。

ベンチが動いた理由を、見た目だけで決めつけないことも大切だ。
