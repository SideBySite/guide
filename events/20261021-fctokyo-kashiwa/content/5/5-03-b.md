## ひとことで

==**前からの守備**とは、相手がパスを出す前に近づいて道を狭める守りだ。== ただし、前へ出た選手の**背後**（その人より自分のゴール寄り）には、空間ができることもある。

## しくみ

**FC東京**の前線（相手ゴールに近い側）にいるマルセロ ヒアン#9や長倉幹樹#26が、柏の後ろへ近づく場合を考えよう。中央の**高宇洋#8**らが次の受け手を見ているかが大切だ。==一人だけが追えば、横や背後に抜け道が残る==のだ。

**柏**は**古賀太陽#4**から中川敦瑛#39らへ通せれば、東京の前線の守りを越えられる。ただ、10月17日の名古屋戦後、中川はボールを失った後の並びを課題に挙げた。

柏も奪い返そうと前へ出すぎれば、東京の前線へ速くパスを通されるおそれがある。

**図案2：追う人と後ろの空間**（上は柏ゴール側。特定の場面を再現した図ではない）

```text
      ↑ FC東京の攻撃方向
  ┌────────────────┐
  │   柏後方 ○   ○   │
  │       ↑    ↑     │
  │     東×    ×東   │ ←前へ追う
  │     （後方の空間）│
  │       東△ △      │ ←備える
  └────────────────┘
  ○＝柏、×＝前へ追う東京、△＝残る東京
```

## 今日の試合で見るなら

柏の**古賀#4**にボールが来たら、東京の前の2人に加えて**永野修都#20**らの中央の位置も見よう。柏が奪い返しに出てきたら、今度は東京の長倉#26が背後へ走るかを追う。==追う人だけでなく、残って備える人にも答えがある==のだ。
