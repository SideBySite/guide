## ひとことで

==**前からの守備**は、相手がパスを出す前に近づく守りだ。== ただし、前へ出た人の**背後**（その人より自分のゴール寄り）が空くこともある。

## しくみ

**FC東京**の前線にいる**マルセロ ヒアン#9**や**長倉幹樹#26**が柏の後ろの選手へ寄るなら、中央の**高宇洋#8**らが次の受け手をふさげるかが重要だ。==1人だけ走ると、横か後ろへ抜け道が残る。==

**柏**は**古賀太陽#4**から**中川敦瑛#39**らへパスを通せれば、東京の前線の守りを越えられる。ただし10月17日の名古屋戦後、中川は球を失った後の並びを課題として話した。柏も奪い返そうと前へ出すぎれば、東京の前線へ速いパスを通されるおそれがある。

**図案2：追う人と後ろの空間**（上が柏ゴール側。特定の場面の再現ではない）

```text
      ↑ FC東京の攻撃方向
  ┌────────────────┐
  │   柏後方 ○   ○   │
  │       ↑    ↑     │
  │     東×    ×東   │ ←前へ追う
  │     （後方の空間）│
  │       東△ △      │ ←備える
  └────────────────┘
  ○＝柏、×＝前へ追う東京、△＝残る東京
```

## 今日の試合で見るなら

柏の**古賀#4**に球が来た瞬間、東京の前の2人だけでなく、**永野修都#20**らが中央を守れるかを見よう。柏が球を奪い返しに来たら、今度は東京の**長倉#26**がその後ろへ走るかを追う。==追う人より、残って備える人が答えになることもある。==
