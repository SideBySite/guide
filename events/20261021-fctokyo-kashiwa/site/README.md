# 随時更新する公開ガイド

公開URL：https://sidebysite.github.io/guide/events/20261021-fctokyo-kashiwa/site/

現時点の保存済み原稿を読み物として公開する途中版。完成を待たずに読める形とし、mainへの原稿追加・修正でGitHub Actionsが再生成して同じURLへ公開する。

## 再生成

リポジトリ直下から `python3 scripts/build_football_site.py` を実行。外部パッケージ不要。表示の型は `scripts/football_template.html`。

採用する本文は、content以下の完成原稿、foundation-v2の37本、両チームのpeople・lineup・roster。旧facts/basicsの長文は新土台の代替にしない。00-Jの追加記事もcontent配下に保存されれば取り込む。未執筆の候補だけを空ページとして公開しない。スラッグはファイルパスから生成し、既存の正式記事IDを改変しない。

原稿の根拠・確認日時を保持する。原稿に先発公式発表を追記した後は、テンプレートの予想表示と配置図も同時更新する。時計やスコアは自動速報しない。ユーザー本人の逸話・maker.md・旧野球版への導線は含めない。
